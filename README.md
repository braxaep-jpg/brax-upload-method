## 🎯 Миссия

**TikTok Video Optimizer** помогает создателям контента минимизировать потери качества при загрузке видео в TikTok. Сервис анализирует видеофайлы, определяет проблемы и автоматически оптимизирует их перед публикацией.

## Компоненты

- `backend/` – API и видеоанализ на основе `ffmpeg`
- `frontend/` – React-интерфейс для загрузки и анализа
- `extension/` – браузерное расширение для интеграции с TikTok upload

## MVP

1. Автоматический анализ видеофайла
2. Определение причин сильной компрессии
3. Рекомендации по оптимальным параметрам
4. Конвертация в TikTok-ready файл
5. Оптимизация и скачивание готового MP4
6. Предупреждение о загрузке видео через браузерное расширение

## Технологии

- Node.js + TypeScript
- Express
- React + TypeScript
- ffmpeg / ffprobe
- Chrome/Firefox extension manifest v3

## Как запустить

1. Установить зависимости: `npm install`
2. Установить ffmpeg в систему и убедиться, что он доступен из командной строки.
3. Запустить бекенд: `npm run backend:start`
4. Запустить фронтенд: `npm run frontend:start`
5. Открыть браузер по адресу `http://localhost:5173`

## Публичный backend

Для публичного backend я подготовил готовый GitHub Actions workflow на Railway. Вам нужно:

1. Зарегистрироваться на Railway бесплатно.
2. Создать Railway Token в настройках аккаунта.
3. В GitHub репозитории добавить секрет `RAILWAY_TOKEN`.
4. В `.github/workflows/deploy-backend-railway.yml` будет настроен deploy при пуше в `main`.

После этого backend будет доступен по домену Railway, например `https://<your-railway-service>.railway.app`.

> Если хотите, можете использовать Render вместо Railway, но для этого потребуется отдельная настройка service и API key.

## Руководство пользователя

### Шаг 1: Подготовка
- Убедитесь, что файл видео в формате MP4 или другом стандартном контейнере.
- Лучше загружать видео с разрешением до 1080p и частотой 60 fps.
- Избегайте HDR, если хотите получить стабильный результат в TikTok.

### Шаг 2: Анализ видео
1. Откройте страницу приложения `TikTok Video Optimizer`.
2. Выберите видеофайл кнопкой `Выберите файл`.
3. Нажмите `Анализировать`.
4. Посмотрите список проблем и рекомендации.

### Шаг 3: Оптимизация
1. Если приложение показало предупреждения, нажмите `Оптимизировать и скачать`.
2. Дождитесь завершения обработки.
3. Скачайте готовый файл `brax-optimized.mp4`.

### Шаг 4: Загрузка в TikTok
1. Откройте TikTok и перейдите к загрузке нового видео.
2. Если вы используете браузерное расширение, при выборе файла появится баннер.
3. Чтобы получить лучший результат, загрузите оптимизированный файл вместо оригинала.

### Как установить расширение
1. Откройте Chrome или другой Chromium-браузер.
2. Перейдите в `Расширения` → `Загрузить распакованное расширение`.
3. Укажите папку `extension/` из проекта.
4. Перейдите на страницу TikTok и начните загрузку видео.

### Первый запуск
1. Запустите бэкенд: `npm run backend:start`
2. Запустите фронтенд: `npm run frontend:start`
3. Откройте `http://localhost:5173`
4. В браузере установите расширение из папки `extension/`.
1. На странице TikTok выберите видео и дождитесь сообщения от TikTok Video Optimizer.

## Ограничения

TikTok продолжает рекодировать видео на своих серверах, поэтому задача проекта — минимизировать дополнительные потери до загрузки.
